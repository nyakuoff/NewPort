These twelve tracks are the Ocarina of Time soundtrack versions of the twelve ocarina songs,
from ENLS's Pre-Looped Music Library:
https://www.enls.eu/prelooped/album/?game=OoT
(converted from .ogg to 192k .mp3 for browser support)

The music is Nintendo's (Koji Kondo and team), used here for an unofficial fan page. It only plays inside
./ocarina.sh (js/ocarina.js): when you play a song correctly, the track plays as the backing and the synth
ocarina plays the phrase on top. If a file is missing the ocarina plays alone, so deleting this folder is safe.
LEAD in js/ocarina.js says where each track's own ocarina starts, so the synth lines up with it.
